# Portfolio Website <img src="https://github.com/JessicaDinova/PortfolioWebsite/blob/main/src/lib/assets/favicon.svg?raw=true" alt="Crown" width="30" height="30" style="vertical-align: middle;">
A complete remake of my original portfolio, built with Svelte and SvelteKit.

**Live Site:** [jessica-dinova.com](https://www.jessica-dinova.com)

## About

This is a redesigned and rebuilt version of my first portfolio website. It showcases my work and projects with a focus on clean, minimalist design and handcrafted visuals.

## Highlights

- **Custom-built design** – No UI component libraries, everything built from scratch <img src="https://github.com/JessicaDinova/PortfolioWebsite/blob/main/src/lib/assets/doodles/stamp.png" alt="Stamp" width="30" height="30" style="vertical-align: middle;">
- **Handdrawn icons** – Every icon was designed and drawn by me
- **No AI-generated content** – Created entirely by hand (Except for this Read.me)
- **Deployed on GitHub Pages** – Hosted with a custom domain

## Tech Stack

- **[Svelte 5](https://svelte.dev)** – Reactive UI framework
- **[SvelteKit](https://kit.svelte.dev)** – Web app framework
- **[Tailwind CSS](https://tailwindcss.com)** – Utility-first CSS
- **[Vite](https://vitejs.dev)** – Build tool

## Getting Started

### Installation

```sh
npm install
```

### Run Locally

```sh
npm run dev
```
